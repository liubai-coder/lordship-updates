# Lordship II 更新发布

这是 Lordship II 的游戏安装包与更新补丁发布仓库。

请从 [Releases](https://github.com/liubai-coder/lordship-updates/releases) 下载游戏版本。仓库首页的「Download ZIP」只是本说明文件，不能启动游戏。

当前正在准备首个带游戏内更新功能的 Windows 基础版本，尚未发布正式 Release。

支持更新的版本可在游戏「设置 → 版本与更新」中检查并下载补丁；补丁验证通过后，重新启动游戏生效。v186 及更早版本需要先安装一次新的基础包。

本仓库只用于发布成品与更新说明。发布者的私有签名密钥、玩家存档和对战服务数据不放在这里。

联机匹配与排位由独立对战服务提供，GitHub Releases 只负责更新分发。
